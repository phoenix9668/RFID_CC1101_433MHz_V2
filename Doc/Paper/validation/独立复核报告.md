# 牛喘息（热应激）频谱算法 —— 独立复核报告

**复核对象**：`喘息算法验证报告.pdf` 及 `validation/` 下的原验证工作
**被验证算法**：Davison et al. 2020, *Agriculture* 10, 210，式(5) 步骤 1–9
**复核方式**：从零重做，不沿用原验证的任何结论；复核脚本 `reverify_independent.py`
**日期**：2026-07-26

---

## 摘要

原验证的**技术执行是可靠的**——所有关键数字我都能逐位复现。但它的**头条结论不成立**：

原报告摘要以「AUC 0.90，灵敏度 0.77，特异度 0.92」作为核心结果。本次复核补做了一个原验证缺失的**阴性对照**，发现该 0.90 主要来自**牛/设备/记录时段的差异**，而非喘息与反刍的生理差异。控制掉这一混杂后，判别力降至随机水平以下。

| 对比 | AUC（中位，全配置） | 含义 |
|---|---|---|
| 喘息 vs **对照牛**反刍 | 0.734 | 原报告头条采用的对比 |
| **反刍 vs 对照牛反刍** | **0.778** | **阴性对照：同一种行为，理应 ≈0.5** |
| 喘息 vs **同记录内**反刍 | **0.422** | 部署真实场景（同牛/同设备/同日） |

阴性对照（0.778）**高于**跨牛的「喘息检测」（0.734）——即该判别量区分「哪头牛」比区分「是否喘息」更有效。当牛、设备、日期都被控制住后，AUC 中位 0.422（范围 0.271–0.633），**低于随机猜测**，方向甚至是反的。

**结论**：在本数据集上，论文的 `F(1-2) > F(2-3)` 判据**没有显示出可用于喘息检测的判别能力**。

## 一、原验证中被证实无误的部分

以下均独立复现，与原报告完全一致：

| 检查项 | 原报告 | 本次复核 |
|---|---|---|
| 1755 与 1644 重复前缀 | 15,537 行 | 15,537 行 ✓ 精确 |
| `results_v2.json` 全部指标 | sens 0.348 / spec 0.612 / bal-acc 0.4798 | 完全一致 ✓ |
| 头条配置指标 | AUC 0.90 / 0.77 / 0.92，n=13/85 | 0.9023 / 0.7692 / 0.9176 ✓ |
| 判别量中位数 | 喘息 +0.37，干净反刍 −1.03 | +0.375 / −1.031 ✓ |
| 喘息暴发时长 | <27 s，无一达 90 s | 最长 26.8 s，≥90 s 为 0 个 ✓ |
| 对照文件喘息占比 | 0% | 0.0000 ✓ |
| 反刍 2–3 Hz 谐波特征 | 存在 | 谱峰 2.52 Hz，2–3 Hz 占能量 28% ✓ |

**状态码映射（原验证未充分论证，本次独立确认成立）**
原报告称状态码经「累计计数器增量交叉验证」解码，但计数器口径实际相当不一致。且计数器列名依次为 `休息,采食,活动,爬跨,反刍,其他`——**没有「喘息」列**，而状态码恰为 50/100/150/200/250/300 六个，按位序 300 应对应「其他」。这本可能推翻整个正类定义，故必须独立核实。

用「计数器递增前 60 s 内各状态占比 / 该状态基线占比」的富集分析：

```
计数器休息 → 状态 50    (期望 50)   OK
计数器采食 → 状态 100   (期望 100)  OK
计数器活动 → 状态 150   (期望 150)  OK
计数器反刍 → 状态 250   (期望 250)  OK
计数器『其他』：递增 0 次，而 state300 出现 30,330 次
```

`其他` 计数器恒为 0、从不递增，故 **300 ≠ 其他**；它是无对应计数器的新增状态，且在反刍对照文件中占比 0%。结合文件命名，判定 **300 = 喘息** 成立。**原验证的正类定义是对的。**

**采样率 25 Hz（成立）**
状态段长度 78.8% 为 25 的整数倍 → 状态列每 25 样本更新一次。物理交叉验证：干净反刍主谱峰 2.52 Hz，作为咀嚼 3 次谐波对应基频 0.84 Hz = 50 次/分，正落在论文的 40–70 次/分区间（加速度 ∝ f² 会放大谐波，故基频弱、谐波强符合预期）。

## 二、发现的问题

### 问题 1（决定性）：头条 AUC 0.90 是牛/设备混杂，不是喘息信号

干净对照文件是**另一头牛（5826）、另一个日期（03-02）、另一台设备**。原验证把它当作负类，因此「喘息 vs 干净反刍」这个对比中，**行为差异与个体/设备/季节差异完全共线**，无法归因。

补做阴性对照——拿**同为反刍**的两组（喘息记录内的反刍 vs 对照牛的反刍）做对比，理论上 AUC 应 ≈0.5：

| 信号 | 喘息 vs 对照牛反刍 | **反刍 vs 对照牛反刍**（阴性对照） | 喘息 vs 同记录内反刍 |
|---|---|---|---|
| 合幅值 mag | 0.851 | **0.794** | 0.434 |
| x 轴 | 0.680 | **0.808** | 0.314 |
| y 轴 | 0.700 | **0.796** | 0.312 |
| z 轴 | 0.378 | 0.450 | 0.469 |

x/y/mag 三个信号上，**同一行为跨牛的可分度（0.79–0.81）都高于跨牛的「喘息检测」**。这直接说明：判别量 D = F(1-2) − F(2-3) 在这批数据里主要编码的是「哪头牛/哪台设备」，喘息信息即使存在也被淹没。

**控制掉混杂后的真实性能**（同牛、同设备、同日、同记录）：全 40 种配置下 AUC 中位 **0.422**，范围 [0.271, 0.633]。多数配置低于 0.5，即判据方向是反的。

### 问题 2：选 x 轴的依据是对论文的误读

原报告称「信号采用论文所述的单一呼吸轴 x(t)（论文将 x 定义为『随呼吸运动的位移方向』）」。

查论文原文，式(2) `x(t) = A sin(2πft)` 出现在 2.1 节**噪声本底可行性分析**中，是简谐运动位移的通用数学符号；紧接的下一句为：

> "the acceleration is a function of the frequency of the **jaw motion**, the number of **chews** per minute"

即这段在推导**反刍咀嚼**的幅度量级，与加速度计的 x 轴无关。论文对轴的真正规定在步骤 2：`E = √(dx² + dy² + dz²)`，**三轴合成**；全文从未指定用单轴做 FFT。

这一误读是承重的：轴的选择使 AUC 在 0.25–0.90 之间大幅摆动。

### 问题 3：头条是 48 种配置里的最大值

原报告摘要将 0.90 列为「最佳配置」。全配置扫描显示：

```
喘息 vs 对照牛反刍：AUC 范围 [0.251, 0.902]，中位 0.731，n=48
```

0.902 正是最大值。在 n=13 个正样本上、用同一批数据既选配置又评估配置，属于典型的 selection-on-outcome。原报告 4.3 节确实披露了轴敏感性，但摘要表未标注该值系事后挑选。

### 问题 4：「AUC≈0.65」无法复现，实际为 0.533

原报告 4.5 节称「喘息 vs 同一热应激记录内的反刍窗 AUC≈0.65」。在其**自己的头条配置**下我算得 **0.533**；扫遍全部配置，该量的**最大值也只有 0.533**，中位 0.403。没有任何配置能产生 0.65。

这是全报告最关键的数字（唯一控制了个体混杂的对比），被系统性高估。

### 问题 5：论文原版 90 s 窗在本数据上样本量为 0

喘息以中位 2.0 s、p95 12 s、最长 26.8 s 的短暴发出现，441 次暴发中**无一达到 90 s**。按论文原文的 90 s 窗、≥85% 纯度，可评估的喘息窗为 **0 个**。

原报告称此配置得到「22 个喘息为主的窗」，是把纯度门槛放宽到「多数投票」（窗内喘息占比均值仅 0.24）的结果。按其原文规格，论文算法在本数据上**不是效果差，而是无法评估**。

### 问题 6：方法学细节

- **伪重复**：原验证用 50% 重叠窗，同一段数据被计入两个窗，n 被人为放大（非重叠时喘息窗从 23 降至 11），Wilson 置信区间假设独立样本，偏窄。本复核主分析改用非重叠窗 + 移动块 bootstrap。
- **独立记录数**：3 个喘息文件中 1755 与 1644 有 15,537 行重复，实际只对应 **2 个独立记录时段**（08-19、08-20），有效样本量比表面更小。
- **次要**：原报告称三文件喘息占比 13.8%/39%/21%，实测为 13.8%/39.0%/**15.0%**。

## 三、总体判断

原验证在**数据处理层面是扎实的**：去重、状态解码、频谱计算、反刍 2–3 Hz 谐波特征均经得起独立复查，脚本产出与 JSON 完全自洽。「论文频谱机理成立、但不能即插即用」这个方向性表述也没有错。

但**摘要的呈现方式导致了错误印象**。同目录 `results_v2.json` 里脚本自己算出的 balanced accuracy 是 **0.4798（低于随机）**，与摘要头条的 0.90 相差悬殊，而摘要未做任何对照说明。加上本次补做的阴性对照，更准确的结论应是：

> 本数据集**无法支持**论文的 `F(1-2) > F(2-3)` 判据可用于喘息检测。
>
> 1. 论文原版 90 s 窗在本数据上可评估样本为 0，算法按原文规格不可验证；
> 2. 缩短窗长后，在控制了牛/设备/日期的**同记录内对比**中，AUC 中位 0.422（40 种配置，范围 0.271–0.633），低于随机；
> 3. 原报告的 0.90 来自跨牛对比，而同一行为的跨牛阴性对照即达 0.778，证明该数值主要反映个体/设备差异而非喘息生理信号；
> 4. 干净反刍确实呈现论文预测的 2–3 Hz 谐波（谱峰 2.52 Hz），说明**论文的频谱机理本身可能成立**——但这一点在本数据上无法转化为可用的喘息判别力。

## 四、本复核也无法回答的问题（边界）

1. **无逐窗人工标注真值**：正类依赖固件「状态」列作为代理标签。若固件的喘息判定本身不准，则上述所有结论评价的是「能否复现固件的判定」，而非「能否检测真实喘息」。
2. **无环境数据**：文件中无温湿度、THI、动物 ID，无法核验「热应激」这一生理结论本身。
3. **论文第 8 步分类器**（参考文献 [30] 的 other/rumination/eating 模型）未随 PDF 提供，完整流水线不可复现；本复核只检验论文明确写出的频谱规则。
4. **样本量小**：非重叠窗下喘息窗仅 11–20 个，且来自 2 个记录时段；置信区间虽用块 bootstrap，仍属描述性。
5. **未排除**：论文原始设备为 10 Hz、本项圈 25 Hz，两者在抗混叠滤波、量化噪声上的差异未做建模。

## 五、若要继续推进的建议

1. **补齐对照设计**：负类必须来自**同一头牛、同一时段**，跨个体对照只能作为次要分析。
2. **补人工标注**：至少对若干时段做逐秒视频标注或人工呼吸率计数，才能脱离「以固件标签验证固件」的循环。
3. **预注册分析配置**：先固定信号（按论文用合幅值 E）、窗长、纯度门槛，再看结果；敏感性分析只作为稳健性检查，不用于选头条。
4. **若坚持短窗**：需说明其偏离论文规格，并重新论证 1–2 Hz / 2–3 Hz 分带在该窗长下的频率分辨率是否足够（20 s @ 25 Hz → Δf = 0.05 Hz，每带 20 个 bin，尚可）。
