## 接线与采集安排

1. 先只连接仪器 PC 口，确认客户端识别设备。不要在仪器尚未识别时改变板卡现有供电。
2. 确认测量电源来自原电池还是外部稳压电源，再断电换接。IoT Power-CC 是测量设备，不能把它当作可任意设置电压的稳压电源；板卡电池端不能直接接 USB 的 5 V。
3. 优先在板卡电池入口测整机电流。四线模式下，原电源接测量输入正负，测量输出正负接原板卡电池输入；仪器自身由 PC 口供电。具体以 [CC 官方接线图](https://wiki.luatos.com/iotpower/cc/parts.html) 和实际端子标识核对。
4. 正式测量前断开 ST-Link、UART 和逻辑分析仪等外接连接，移除可能的旁路供电；独立上电启动 Release。记录固件哈希、供电电压、接线方式和测试起点。
5. 按设备支持的最高 10 kHz 上报速率保留原始波形，先检查空载基线和量程，再记录建议不少于 45 分钟的数据，以覆盖相邻发送峰之间至少一个完整 20 分钟周期。保存原生 `.iotpl`，并在可用时导出带明确单位的原始 CSV；原始采样与图表显示抽稀应区分。
6. 记录结束后再接回探针，保存终点 EEPROM，核对新运行段的历史计数和复位次数。启动残窗、受控复位窗口和真正断流应单独标记。

官方说明：CC 的 [型号与能力](https://wiki.luatos.com/iotpower/cc/index.html)、[连接方式](https://wiki.luatos.com/iotpower/cc/parts.html)、[客户端导出功能](https://wiki.luatos.com/iotpower/pc.html)。双线模式只能用于电流测量，其电压读数没有参考意义；这种情况下不直接用软件显示的功率计算能量。
